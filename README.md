# TumanIOWebApp
Этот проект представляет собой веб-приложение для продажи вендинговых аппаратов ароматизации автомобилей (TumanIO). Он включает в себя маркетинговый сайт с конструктором конфигурации, калькулятором окупаемости и формой обратной связи, а также административную панель для управления заявками. Разработан на PHP и MySQL, с использованием современного адаптивного интерфейса.
